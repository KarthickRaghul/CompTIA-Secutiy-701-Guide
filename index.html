Critical Commands for PBQs

CompTIA PBQs frequently drop you into command-line simulators. Here are the core flags and commands tested on the exam.

NMAP (Network Mapper) Recon & Auditing
nmap -sS -p 80,443 -sV 192.168.1.50

-sS: Stealth SYN scan (half-open). -sV: Service/version detection. -O: OS fingerprinting. -sU: UDP port scan.

NETCAT (The Swiss-Army Knife) Pivoting & Triage
nc -lvp 4444  |  nc -zv 10.0.0.1 80

-l -p 4444: Listen on port. -zv: Zero-I/O port banner scanning without payload. Look for rogue netcat processes in PBQs!

TCPDUMP (Packet Capture) Network Forensics
tcpdump -i eth0 -nn -w capture.pcap port 443

-i <iface>: Interface. -nn: Don't resolve hostnames/ports. -w: Write to file. -r: Read PCAP file for inspection.

JOURNALCTL & LOGGING Linux Incident Response
journalctl -u ssh --since "1 hour ago" -f

Queries systemd system journal. -u <service> filters unit logs. logger "msg" sends synthetic logs to /var/log/syslog.

CHMOD (Linux Permission Math) Least Privilege
chmod 750 script.sh   (r=4, w=2, x=1)

First digit = User (7=rwx), Second = Group (5=r-x), Third = Others (0=none). Used in PBQs to revoke unauthorized access on sensitive keys.

HPING3 & NETSTAT Packet Crafting & Sockets
hping3 -S -p 80 target  |  netstat -tulpn

hping3 -S tests firewall SYN handling. netstat -tulpn lists all listening TCP/UDP sockets with Process IDs (PIDs) to terminate.

Author's Real Exam Breakdown (24/11/2026)

Detailed breakdown of the 3 exact Performance-Based Question scenarios encountered during the author's passing exam.

1

Password & Data Leak Triage

IAM & Identity Governance
You are given a database table showing employee accounts, date of joining, password strings, and last activity timestamps. You must identify password flaws (length, rotation, reuse, complexity).

Then a breach scenario occurs where credentials leaked. You must classify which leaked data is acceptable to remain exposed vs catastrophic (e.g. temporary OTP vs salted password hash vs plain text).
Key Strategy: Prioritize short expiration times and one-time tokens (OTP) as low-impact data, while flagging unrotated admin credentials as immediate critical remediations.
2

Network Segmentation & Malware Triage

Firewall & Architecture
You are provided a network diagram with an R&D subnet (192.168.x.x) and an Engineering subnet (10.10.x.x) divided by a central perimeter firewall.

You must inspect 6 simultaneous host log files and packet headers to determine which systems are infected, which spread malware, and which remained completely contained.
Key Strategy: Trace outbound connection timestamps and unusual port activity (e.g. SMB port 445 or random high ports) crossing the firewall boundaries to isolate patient zero.
3

Linux SOC Incident Response (Hardest)

Root CLI & Malware Eradication
You are dropped into two compromised Linux servers with root privileges. Two threat intelligence reports list suspicious malicious external IPs.

Using a restricted set of Linux utilities (netcat -o, ls -l, ps, kill), you must correlate suspicious network connections, identify the rogue process PID, kill it, find the malicious dropper file, and purge persistence.
Key Strategy: Always check active sockets with netstat or lsof first to map the external IP back to a specific Process ID before executing kill -9.
